## 2. 핵심 재미 & 벤치마크

### 벤치마크 분석
- **Match Factory! (Zynga)**: 3D 오브젝트 더미에서 아이템을 탭 → 하단 7칸 트레이에 수집 → 같은 아이템 3개가 모이면 소멸. 트레이가 가득 차면 패배. 명확한 규칙 + 물리 기반 더미가 주는 "실물 정리" 쾌감.
- **갈매기 게임 (위플레이 스타일 모션 게임)**: 기기 자체를 기울이고 흔들면 화면 속 오브젝트가 중력을 따라 움직임. 조작 자체가 장난감 같은 재미.

### 코코 매치의 결합 방식
1. 통(빈) 안에 3D 아이템 수십 개가 물리로 쌓여 있음
2. **폰을 기울이면 중력 방향이 바뀌어 아이템이 그쪽으로 와르르 쏠림** → 아래 깔린 아이템을 자연스럽게 발굴
3. **폰을 흔들면 아이템이 튀어오르며 뒤섞임** (무료 셔플이자 조작 재미)
4. 탭으로 수집 → 3매치 소멸 → 통 비우면 클리어

모션이 단순 기믹이 아니라 **"깔린 아이템을 찾는 핵심 전략 수단"** 이 되는 것이 설계 포인트.

## 3. 코어 게임플레이 루프

```
레벨 시작 → 아이템 더미 낙하 생성
   ↓
[반복] 기울여서 탐색 ↔ 탭해서 수집(트레이 7칸) ↔ 3개 매치 시 소멸
   ↓
승리: 모든 아이템 소거          패배: 트레이 가득 참 / 시간 초과
   ↓
별점·점수 → 다음 레벨 해금 → 다음 레벨
```

### 상세 규칙
- **트레이**: 7칸. 수집한 아이템은 같은 종류끼리 자동 정렬.
- **매치**: 같은 아이템 3개가 트레이에 모이면 즉시 소멸 + 점수 획득 + 햅틱.
- **패배 조건 1**: 매치가 안 된 상태로 트레이 7칸이 가득 참.
- **패배 조건 2**: 제한 시간 종료.
- **승리 조건**: 보드의 모든 아이템(종류당 3의 배수)을 매치로 소거.
- **점수**: 매치당 +30점, 클리어 시 남은 시간 × 5점 보너스.

### 조작
| 입력 | 동작 |
|---|---|
| 탭 | 맨 위에 보이는 아이템 수집 |
| 기기 기울이기 | 중력 방향 변경 → 아이템 쏠림 (실시간 60fps) |
| 기기 흔들기 | 아이템이 위로 튀며 뒤섞임 (쿨다운 0.5초) |

## 4. 아이템 & 테마

**테마: 과일에서 야식으로** — 초반 레벨은 신선한 과일, 레벨이 오르면 야식 메뉴가 계속 추가된다.

- **과일 7종** (레벨 1~): 🥥 코코넛 · 🍎 사과 · 🍌 바나나 · 🍓 딸기 · 🍊 오렌지 · 🍉 수박 · 🍍 파인애플
- **야식 12종** (레벨 16부터 3레벨마다 1종씩 추가): 🍗 치킨 · 🍕 피자 · 🍔 햄버거 · 🌶 떡볶이 · 🍜 컵라면 · 🥟 만두 · 🍘 김밥 · 🍟 감자튀김 · 🌭 핫도그 · 🍩 도넛 · 🥤 콜라 · 🍙 삼각김밥

총 19종. 한 레벨에는 "가장 최근 해금된 10종"만 등장(슬라이딩 윈도우)해 고레벨은 야식 위주가 되며, 총 아이템 수 상한(90개)을 유지한다.

- 각 아이템은 SceneKit 프리미티브 조합으로 만든 실물형 3D 모델 (ItemNodeFactory) → 추후 전문 3D 에셋으로 교체 가능.

## 5. 레벨 디자인 & 난이도 곡선

총 **50레벨** (공식 기반 생성, 추후 수제 튜닝):

| 파라미터 | 공식 | 레벨 1 | 레벨 25 | 레벨 50 |
|---|---|---|---|---|
| 아이템 종류 수 | `min(3 + (n-1)/3, 10)` | 3종 | 10종 | 10종 |
| 종류당 트리플 수 | `min(2 + (n-1)/5, 3)` | 2 | 3 | 3 |
| 총 아이템 수 | 종류 × 트리플 × 3 | 18개 | 90개 | 90개 |
| 제한 시간 | `60 + 총아이템 × 2`초 | 96초 | 240초 | 240초 |

난이도 축: 아이템 수 증가 → 더미가 깊어져 **기울여서 발굴하는 플레이**가 강제됨, 종류 증가 → 트레이 관리 난이도 상승.

## 6. 부스터 (레벨당 지급)

| 부스터 | 효과 | 지급 |
|---|---|---|
| 🌪 셔플 | 전체 아이템을 크게 튀어오르게 함 (흔들기 강화판) | 3회 |
| 🧲 자석 | 트레이 상황에 맞는 최적 아이템 트리플을 자동 완성 | 2회 |
| ⏰ +30초 | 제한 시간 30초 추가 | 1회 |

자석은 트레이에 2개 있는 종류 → 1개 있는 종류 → 보드 트리플 순으로 스마트 선택하며, 트레이 오버플로우가 나지 않을 때만 발동.

## 8. 기술 설계

| 영역 | 선택 | 이유 |
|---|---|---|
| UI | SwiftUI | HUD/메뉴 생산성, 최신 iOS 표준 |
| 3D/물리 | SceneKit | 내장 물리엔진, 외부 의존성 0, 앱 용량 최소 |
| 모션 | CoreMotion (`CMDeviceMotion`) | 60Hz 중력 벡터 → `physicsWorld.gravity` 매핑, `userAcceleration`으로 흔들기 감지 |
| 햅틱 | UIKit Feedback Generators | 수집/매치/실패 피드백 |
| 저장 | UserDefaults (`@AppStorage`) | 해금 레벨 (MVP 수준에 충분) |
| 최소 버전 | iOS 17 | 최신 SwiftUI API 사용 |

### 모션 → 중력 매핑
디바이스 중력 벡터 `(gx, gy, gz)` → 씬 중력 `(gx·k, clamp(gz·k, max: -2), -gy·k)`
- 수평 성분 1.6배 증폭으로 반응감 강화
- Y(아래 방향) 성분은 최소 하방력을 유지해 아이템이 천장으로 붙는 상황 방지
- 시뮬레이터(모션 없음)에서는 기본 중력으로 정상 플레이 가능
