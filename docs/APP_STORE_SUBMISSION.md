## 1. 개인정보 처리방침 URL (광고 앱 필수)

`docs/privacy-policy.html`이 이미 만들어져 있습니다. GitHub Pages로 무료 호스팅하세요:

1. GitHub 저장소 → **Settings** → **Pages**
2. Source: **Deploy from a branch** 선택
3. Branch: `main` (머지 후) 또는 현재 작업 브랜치 선택, 폴더는 **/docs** 선택 → Save
4. 1~2분 후 URL 생성: `https://sangmin082.github.io/coco_match/privacy-policy.html`
5. 브라우저에서 열리는지 확인

> 이 URL은 3단계의 "개인정보 처리방침 URL"과 "지원 URL" 두 곳에 사용합니다.

## 2. 스크린샷 촬영

**필수: 6.9인치** (iPhone 15 Pro Max 이후 기종으로 촬영하면 자동으로 맞음).
아이폰에서 게임을 켜고 전원+볼륨업 버튼으로 캡처하세요.

추천 장면 5장 (앱스토어는 첫 2~3장이 승부처):
1. **아이템이 가득한 박스** — 야식+과일이 중앙에 뭉쳐 있는 장면 (첫 장 추천)
2. **기울여서 쏠린 순간** — 아이템들이 한쪽으로 와르르 몰린 장면
3. **트레이에 2개 모인 상태** — 매치 직전의 긴장감
4. **레벨 클리어 팝업** 🎉
5. **레벨 선택 화면**

> 팁: 설정 → 제어 센터에서 화면 기록을 추가하면 영상도 찍을 수 있고, 앱 미리보기 영상(선택)으로 올릴 수 있습니다.

## 4. App Privacy 설문 정답지 (AdMob 기준)

App Store Connect → 앱 → **App Privacy** 섹션. AdMob SDK가 수집하는 항목 기준입니다:

**"데이터를 수집합니까?"** → **예**

수집 항목 3가지 선택:

| 데이터 유형 | 세부 항목 | 용도 | 신원 연결 | 추적 사용 |
|---|---|---|---|---|
| 식별자 | 기기 ID | 제3자 광고 | 아니요 | **아니요** |
| 사용 데이터 | 광고 데이터 | 제3자 광고 | 아니요 | **아니요** |
| 진단 | 성능 데이터, 기타 진단 데이터 | 앱 기능 | 아니요 | 아니요 |

> "추적 사용: 아니요"인 이유 — 앱이 ATT(앱 추적 투명성) 권한을 요청하지 않으므로
> 기기 광고 식별자(IDFA)를 통한 추적이 이루어지지 않습니다.
> ⚠️ Google 정책이 바뀔 수 있으니 제출 전 [Google의 공시 가이드](https://support.google.com/admob/answer/10787803)를 한 번 확인하세요.

## 5. 심사용 빌드 선택 → 제출

1. 1.0 제출 준비 페이지의 **빌드** 섹션 → **(+)** → 최신 TestFlight 빌드 선택 (테스트하던 빌드 그대로 제출 가능)
2. **수출 규정** 질문은 자동 통과 (앱에 이미 설정됨)
3. **심사 정보**: 로그인 없는 게임이므로 데모 계정 불필요. 메모에 한 줄 추가 추천:
```
This is a physics-based tile-matching puzzle game. Tilt and shake the device to move items. No login required. Ads are provided by Google AdMob.
```
4. **심사에 제출** 클릭 → 보통 1~3일 내 결과

## 6. 출시 후 할 일

- **AdMob 연결**: AdMob 콘솔 → 앱 → 앱 설정 → **앱 스토어에 연결** (출시된 앱스토어 링크 검색·연결) → 앱 확인 완료 후 실광고 게재 시작 (연결 후 최대 몇 시간~며칠 소요)
- **app-ads.txt** (권장): AdMob 콘솔 안내에 따라 지원 사이트에 등록 — GitHub Pages 사용 시 `docs/app-ads.txt` 파일 추가로 대응 가능
- 첫 리뷰·평점 요청, ASO 키워드 성과 모니터링
